# 🌦️ Weather App (React)

A simple weather application built using React that fetches real-time weather data using an API.

---

## 🚀 Features

- Search weather by city name
- Displays temperature, humidity, and weather condition
- Real-time data using OpenWeatherMap API
- Clean UI

---

## 🛠️ Tech Stack

- React (useState)
- JavaScript (ES6+)
- HTML & CSS
- OpenWeatherMap API
